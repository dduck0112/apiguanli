# 中转站管家

一个管理 [NewAPI](https://github.com/QuantumNous/new-api) 类 AI 中转站的安卓 App。不用再一个个登录网页去复制地址和 Key、查余额、比价格。

## 功能

- **账号密码登录 NewAPI 站点**：支持旧版和新版 NewAPI，包括两步验证（2FA）和密码加密登录。
- **余额和使用记录**：首页汇总所有站点的余额；设置「1 元 = 多少额度」后显示真实金额。
- **令牌**：查看、复制令牌，一键复制「地址 + Key」。站点不显示完整 Key 时，可以手动粘贴保存。
- **只填 URL + Key**：不登录账号也能添加。可以选择自动补全 OpenAI（`/v1/chat/completions`）或 Anthropic（`/v1/messages`）后缀，也可以不补全、原样使用地址。
- **跨站比价**：按模型搜索，把各站价格换算成人民币后对比；常用模型可以收藏。
- **模型测试和对话**：测试模型是否可用，内置类似「游乐场」的对话，支持 OpenAI 和 Anthropic 格式、流式输出和思考过程。
- **模型体检**：检查中转站的模型有没有「掺水」或被换成别的模型。检查项包括模型名、隐藏提示词、分词指纹、稳定性、工具调用、结构化输出、长上下文等，可以和你信任的渠道逐项对比。
- **每日签到**：在开启了签到的站点上一键签到，也可以在打开 App 时自动签到。

## 安装

到 [Releases](../../releases) 下载最新的 `.apk`，在安卓手机上安装。需要 Android 8.0 及以上。

## 隐私和安全

- 访问令牌和 API Key 用安卓系统密钥库（Android Keystore）加密，只保存在本机，不上传任何服务器。
- 密码只在登录时使用，不会保存。
- 新版 NewAPI 登录时，App 会创建一个名为「中转站管家 日期」的访问令牌，权限只有查看信息和签到。你可以在网页的「访问令牌」里随时撤销。
- 关闭了系统备份，数据不会被备份到云端。

## 自己编译

需要 JDK 17 和 Android SDK（compileSdk 36）。

```bash
./gradlew assembleDebug
```

正式版签名需要在项目根目录放 `keystore.properties` 和对应的密钥文件（已在 `.gitignore` 中排除）。没有这两个文件时，release 包不会被签名。
